==========================================================
  ИНСТРУКЦИЯ ПО РАБОТЕ С GIT — проект "МирИгрушек"
  Минимум 3 коммита. Локальный репозиторий.
==========================================================

Открой терминал (PowerShell, командную строку или Git Bash)
В ПАПКЕ ПРОЕКТА — там, где лежит файл MirIgrushek.sln.

Чтобы перейти в папку, используй команду cd, например:
  cd C:\Users\user\source\repos\MirIgrushek


----------------------------------------------------------
ШАГ 0. Проверка, что git установлен
----------------------------------------------------------
git --version

(Если выводит версию — всё хорошо. Если "command not found" —
 скачай и установи Git с сайта git-scm.com, потом перезапусти терминал.)


----------------------------------------------------------
ШАГ 1. Настройка имени и почты (делается один раз на ПК)
----------------------------------------------------------
git config --global user.name "Твоё Имя"
git config --global user.email "твой@email.com"


----------------------------------------------------------
ШАГ 2. Инициализация репозитория
----------------------------------------------------------
git init


----------------------------------------------------------
КОММИТ 1 — База данных (Модуль 1)
----------------------------------------------------------
git add .gitignore Database/
git commit -m "Модуль 1: база данных, скрипты и ER-диаграмма"


----------------------------------------------------------
КОММИТ 2 — Приложение (Модули 2-3)
----------------------------------------------------------
git add MirIgrushek.sln MirIgrushek/
git commit -m "Модули 2-3: WPF-приложение, авторизация, список и редактирование товаров"


----------------------------------------------------------
КОММИТ 3 — Документация (ТЗ и README)
----------------------------------------------------------
git add README.md Техническое_задание.docx
git commit -m "Документация: техническое задание и README"


----------------------------------------------------------
ПРОВЕРКА — должно показать 3 строки (3 коммита)
----------------------------------------------------------
git log --oneline


==========================================================
  ДОПОЛНИТЕЛЬНО (если нужно закоммитить .exe)
==========================================================
Сначала собери проект в Visual Studio в режиме Release
(вверху смени Debug на Release, потом Build -> Rebuild Solution).
Затем выполни:

git add -f MirIgrushek/bin/Release/net8.0-windows/MirIgrushek.exe
git commit -m "Исполняемый файл приложения"

(флаг -f заставляет git добавить файл, несмотря на .gitignore)


==========================================================
  ЕСЛИ ОШИБЛИСЬ
==========================================================
- Посмотреть текущее состояние:        git status
- Отменить последний коммит (файлы
  останутся, коммит снимется):          git reset --soft HEAD~1
- Посмотреть список коммитов подробно:  git log
